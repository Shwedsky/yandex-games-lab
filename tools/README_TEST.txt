MUTANTS — QUICK TEST

Windows desktop:
1. Extract the whole ZIP into a normal folder.
2. Double-click START_TEST.cmd.
3. The game opens automatically in your default browser.
4. When finished, return to the black PowerShell window and press Enter.

Phone on the same Wi-Fi:
- START_TEST.cmd also prints a local-network URL when Windows can detect one.
- Open that URL on the phone while the test window remains open on the PC.
- Windows Firewall may ask once to allow Python on private networks.

The URL contains ?mockAds=1. This only simulates a successful rewarded ad when the Yandex SDK is absent, so revive/remove/upgrade/x2 can be tested locally. Production builds without that query parameter do not grant fake rewards.

Human test gate:
- Does dropping feel responsive?
- Do equal creatures always merge correctly?
- Does the overflow warning feel understandable and fair?
- Are the collection and rewarded actions obvious rather than annoying?
- Any freeze, broken layout, accidental click, or unreadable text?
